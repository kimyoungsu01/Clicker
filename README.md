### 클리커 게임 소개
- 클리커 게임(또는 방치형 게임)은 단순한 클릭 동작으로 자원을 획득하고, 이를 통해 점진적으로 성장하는 게임 장르입니다. 지속적인 보상 시스템으로 강한 중독성과 성취감을 제공합니다.

### 팀 전략
</summary>임무 분담</summary>

- 게임매니저 - 김영수 
- 클릭이벤트 - 구슬기 
- 적 및 스테이지 - 홍지한 
- 플레이어 능력치 및 업그레이드 - 오규범 무기 및 업그레이드 - 신승민

### PlayerData 핵심 기능 구현
</summary>Player 데이터 생성자를 구현하여 
플레이어가 행동하는 것들을 쉽게 관리하기 위해
